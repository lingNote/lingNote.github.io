常见问题

需要注册吗？收费吗？

手机号 + 验证码登录即可，不需要密码。免费版可以直接开始记，达到额度上限后再考虑升级套餐。

下载时提示「无法安全下载」或被拦截？

安卓需要在系统设置里允许「安装未知来源应用」；如果是在微信里打开的，请点右上角「···」→「在浏览器打开」后重新下载。

Windows 版为什么是 zip 包？

免安装设计：解压到任意目录，双击 lingnote.exe 就能用，不写注册表、不留卸载残留，删掉文件夹即卸载。

换手机或重装系统，数据会丢吗？

不会。同一账号登录后会自动从服务器同步回来，本地缓存只是离线副本。

我的笔记存在哪里？别人能看到吗？

存在部署方自己的服务器与 MySQL 数据库中，不经过第三方网盘或分析服务；数据仅与你的账号关联。

支持 iPhone / macOS 吗？

当前提供 Windows、Android 与网页版。iPhone / macOS 可直接用网页版，原生客户端在规划中。
